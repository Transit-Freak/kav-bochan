# איסוף מהמחשב הביתי

כשארכיון האינטרנט חוסם את השרתים של GitHub, אפשר לאסוף את הצילומים שנשארו
ממחשב אחד בבית, באותו קצב מנומס: `tools/home_collect.py`.

- הקובץ `ACTIVE` בתיקייה הזאת עוצר את האיסוף ב-GitHub, כדי ששני המקומות לא ירוצו
  יחד. כשהאיסוף בבית נגמר, מוחקים אותו.
- את `website-home.json.gz` שהסקריפט יוצר מעלים לתיקייה הזאת (Add file → Upload
  files). העלאה מפעילה את `website-history.yml`, שקולט את הצילומים ומפרסם אותם.
- צילום שכבר נקרא ב-GitHub לא מוחלף; צילום שנכשל כאן מוחלף בתוצאה מהבית.

## העלאה אוטומטית

אם ליד הסקריפט יש קובץ `github-token.txt` ובו מפתח GitHub (fine-grained, רק המאגר
הזה, הרשאת Contents: Read and write), הסקריפט מעלה לבד רק את מה שחדש, בקובץ קטן
`part-<תאריך-שעה>.json.gz`:
- בהפעלה: כל מה שנאסף ולא עלה לפני שהמחשב נכבה;
- כל 30 דקות, כשנמצאו קווים חדשים (בתדירות גבוהה יותר הפרסום של האתר, 11–12 דקות, מתבטל שוב ושוב);
- כשהוא נעצר.

ב-`kavbochan-home/uploaded.json` במחשב נשמר מה כבר עלה, כך ששום צילום לא עולה פעמיים
ואף אחד לא נשמט. `website-history.yml` קורא את כל הקבצים `*.json.gz` בתיקייה הזאת.
המפתח נשאר רק במחשב ולא נשלח לשום מקום חוץ מ-GitHub.
