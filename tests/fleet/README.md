# בדיקת "צי הרכבים" בדפדפן

רצה ב-GitHub על כל PR שנוגע בקוד של הכלי (`fleet/`, בלי `data/`), בנתונים הקבועים או בבדיקה עצמה —
ה-workflow `.github/workflows/fleet-tests.yml`. לא רצה על עדכוני הנתונים של הלילה.

המטרה: אם הבדיקה עוברת לפני שינוי בקוד (למשל פיצול `index.html` לכמה קבצים) וגם אחריו — הכלי עדיין עובד.

## מה נבדק

`page.mjs` פותח את `fleet/index.html` ב-Chromium מול הנתונים הקבועים שב-`tests/fixtures/fleet`
(389 רכבים, 29 חברות, 329 דגמים — כ-280KB), בלי רשת חיצונית, ולוחץ כמו משתמש:

| מסך | מה נבדק |
|---|---|
| המסך הראשי | חמשת המספרים למעלה, "השידורים עד", כרטיס לכל חברה לפי הסדר, חברות מוסתרות (מספר 21, "מפעיל N") לא מופיעות |
| דף חברה | הכותרת והמספרים, הכתובת, "איפה אני", שלוש הלשוניות, טבלת הרכבים, הסינון "פעילים" ו"הכול", מיון לפי שנתון בשני הכיוונים, לשונית השנתונים, חזרה למסך הראשי, קישור ישיר |
| דגמים | כרטיס לכל דגם — כל 329, בלי הגבלה של 48 — מהגדול לקטן, "הכי מקולקלים", "מדד אמינות הדגמים" |
| דף דגם | הגרף "אצל אילו חברות הדגם הזה נפוץ" (החברות, המספרים ורוחב הפסים), ההערה שמונה את החברות עם נסיעות בודדות, "אמינות הדגם", הטבלה, סינון לפי שנתון; ובדגם של רכבי קבלן — שאין הערה כזו |
| פתיחת שורה | ▾ בעמודת החברה פותח שורה לכל חברה עם תאריכים ועם "נסיעות בודדות", בלי לפתוח את כרטיס הרכב, ולחיצה שנייה סוגרת |
| כרטיס רכב | נפתח בלחיצה על שורה ובקישור ישיר; הפרטים מהמאגר הממשלתי, ממאגר ציי הרכב ומהשידורים; "איפה הוא נסע"; סגירה; הכתובת |
| חיפוש | הצעה לדגם ולמספר רכב, ומעבר לדף הדגם |
| "עוד" ושאר המצבים | התפריט, "כל הרכבים" (200 שורות ו"הצגת עוד"), ומעברים, ערים, אשכול ביום, לפי קו ונתונים חשודים — שנטענים בלי שגיאה |
| טלפון | המסך הראשי, דף חברה ורשימת הדגמים ברוחב 390 — בלי גלילה לצדדים |

בסוף נבדק שלא הייתה שגיאת JavaScript בדף. לא משווים פיקסלים.
קבצי נתונים שאין בנתונים הקבועים (ערים, אשכולות, קווים, נתונים חשודים) מחזירים 404, והדף אמור להציג הודעה ולא להישבר.

בדיקות היחידה של `moves.js` נשארות ב-`tests/fleet-moves.test.mjs`.

## הרצה מקומית

```
npm i --no-save --prefix /tmp/pw playwright
/tmp/pw/node_modules/.bin/playwright install chromium
NODE_PATH=/tmp/pw/node_modules node tests/fleet/page.mjs
```

`CHROME=/path/to/chrome` — דפדפן אחר. ההרצה לוקחת כעשר שניות.

## כשהבדיקה נכשלת

הפלט מראה לכל בדיקה שנכשלה מה היה צפוי ומה יש על המסך. אם השינוי מכוון (ניסוח חדש, עמודה חדשה) —
מעדכנים את הצפוי ב-`page.mjs` באותו PR.

## החלפת הנתונים הקבועים

`python3 tests/fleet/make_fixtures.py` בונה אותם מחדש מ-`origin/main` (קורא קובץ-קובץ עם `git show`, בלי להוריד את
תיקיית הנתונים). אחר כך המספרים והשמות בראש `page.mjs` (`OP`, `KAB`, `TOP_OP`, `M1`, `M2`) צריכים עדכון לפי מה
שהדף מציג — אחרי שבדקתם בעין שהוא נכון.
