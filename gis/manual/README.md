# קבצים ידניים משכבות משרד התחבורה

data.gov.il חוסם הורדות משרתי GitHub (30.09.2026), ולכן שכבות משרד התחבורה ב-GIS
נבנות מקבצים שמורידים ידנית מהאתר ומעלים לתיקייה הזו.

איך:
1. נכנסים לעמוד המאגר ב-data.gov.il (הקישורים למטה) ומורידים את קובץ ה-ZIP (לא KMZ).
2. **לא משנים את שם הקובץ.**
3. ב-GitHub: בתיקייה הזו → Add file → Upload files → גוררים את הקבצים → Commit.
4. הריצה הבאה של gis-layers (כל יום ראשון, או הפעלה ידנית) הופכת אותם לשכבות.
