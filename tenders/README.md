# מסכם המכרזים

אתר סטטי בעברית שמציג מה כתוב במכרזי התחבורה הציבורית: הקווים, השינויים בהם (ציטוטים מהמסמכים) והמסלולים, מה רץ היום, וכל תנאי המכרז לפי נושא (שכר, תמורה, ערבויות, קנסות, צי…) — לכל סעיף שורת "בקצרה" במילים פשוטות שנוצרת בחוקים קבועים, והטקסט המלא מהמסמך מתחתיה. מפות שמופיעות במסמכים מועתקות כצילום עמוד. הכול בקוד, בלי מודל שפה.

הכתובת הציבורית: https://transit-freak.github.io/kav-bochan/tenders/

קובצי האתר והנתונים נמצאים בתיקייה זו. סקריפטי האיסוף בתיקיית scripts.
העדכון רץ כל לילה ב-GitHub Actions (tenders-collect.yml).
החיפוש אינו מבטיח כיסוי מלא של כל ניסוח וכל מפרסם.

להנחיות עדכון ובדיקות יש לקרוא את AUTOMATION.md. אין לשנות את יתר האתרים במאגר.
