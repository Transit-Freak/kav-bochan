# הקו הבוחן

פלטפורמה חופשית לבחינת התחבורה הציבורית בישראל, על בסיס הנתונים הרשמיים של
משרד התחבורה. האתר: <https://kavbochan.app/>

הדומיין `kavbochan.app` מחובר דרך Cloudflare מ‑17.09.2026 (קובץ `CNAME` בשורש המאגר).
הכתובת הישנה `transit-freak.github.io/kav-bochan/` ממשיכה לעבוד ומפנה אוטומטית לדומיין החדש.

מסך פתיחה אחד מוביל לכלים האלה:

## הכלים

| כלי | מה הוא עושה |
|---|---|
| **קו פח** | איתור קווים ריקים ובזבזניים, מועמדים לביטול או צמצום. |
| **הקו המוזהב** | איתור הקווים המצטיינים, הסטנדרט שאליו כדאי לשאוף. |
| **קו באג** | תקלות גאומטריות במסלולי הקווים (עיקופים ובליטות מיותרים). אפליקציה עצמאית במאגר [kav-bug](https://github.com/Transit-Freak/kav-bug). |
| **הקו בזמן** (`line-history/`) | היסטוריית קווים מ-2003 ועד היום (צילומי אתרי המידע לנוסעים 2003–2015, נתוני משרד התחבורה מ-2012): מסלול, שרטוט, תחנות, רציפים ושמות, עם התראות על שינויים חדשים. |
| **הקו המודיע** (`alerts/`) | שינויי השירות הזמניים של משרד התחבורה (עבודות, אירועים, הפגנות, חסימות), דרך [bus-alerts.com](https://bus-alerts.com/): הסיבה, התחנות שבוטלו זמנית והתחנות החלופיות, והמסלול העוקף המשוער לפי נוסח ההודעה. מתעדכן פעמיים ביום. |
| **איפה האוטובוס נתקע** (`bus-speed/`) | מהירות האוטובוסים בכל קטע רחוב, בכל כיוון ובכל שעה, לפי המיקום שהאוטובוסים משדרים כל דקה (מקובצי ה-SIRI של [דאטאבוס](https://open-bus-stride-api.hasadna.org.il/), הסדנא לידע ציבורי), 28 הימים האחרונים. השוואת יישובים לפי גודל והורדה לאקסל. מתעדכן כל לילה. |
| **מדד דיוק האוטובוסים** (`bus/`) | כל אוטובוס בארץ מול הלו"ז, תחנה אחרי תחנה: כמה הגיעו בזמן, מי יצא מוקדם ומי איחר — לפי קו, מפעיל, אשכול, עיר ושעה, יום אחרי יום. |
| **מדד אמינות הרכבת** (`rail/`) | כל רכבת שבלו"ז מול המיקום ששידרה בפועל: איחור לפי קו, תחנה ושעה, וכל נסיעה על המפה. |
| **צי הרכבים** (`fleet/`) | כל האוטובוסים שנצפו בשידורי האיכון: לאיזו חברה כל רכב שייך, מאיזו שנה, מתי נצפה, פרטיו במאגר הרישוי ומעברים בין חברות וערים. |
| **רציף כפול** (`ratzif/`) | שני אוטובוסים או יותר שאמורים לצאת מאותו רציף מוצא באותה דקה, לפי לוח הרישוי הרשמי. |
| **המחירון** (`fares/`) | כמה עולה הנסיעה — בודדת, יומית וחודשית — לכל קו או בין שתי תחנות. |
| **התחנה הבאה** (`next-station/`) | תחנות ששמן אינו תואם לרחוב שבכתובתן. |
| **הקו המדלג** (`skip-stops/`) | קווים עירוניים שחולפים ליד תחנה פעילה בלי לעצור בה. |
| **נגישות אזורי תעשייה** (`parks/`) | ציון נגישות לתחבורה ציבורית ל-414 אזורי תעשייה ותעסוקה: תדירות בשעות השיא והליכה מהמפעל הרחוק לתחנה, מפה, דירוג ודו"ח. בשיתוף מחלקת קידום תחבורה ציבורית בהסתדרות. |

## איך זה בנוי

- **אתר סטטי בלי שלב בנייה.** מסך הפתיחה וכלי "קו פח / הקו המוזהב" הם אפליקציית
  React ש‑`index.html` טוען ישירות ו‑Babel מקמפל בדפדפן. שאר הכלים הם דפי HTML
  ו‑JavaScript רגילים, כל אחד בתיקייה שלו.
- **הנתונים מוכנים מראש ב‑GitHub Actions.** התהליכים ב‑`.github/workflows/` מורידים
  בלילה את קובצי ה‑GTFS, שידורי המיקום (SIRI דרך דאטאבוס), לוחות הרישוי, מאגרי
  משרד התחבורה ומסמכי המכרזים, מחשבים את התוצאות ושומרים אותן כקובצי JSON במאגר.
  האתר רק קורא את הקבצים, בלי שרת. הסקריפטים ב‑`tools/` ובתיקיית `scripts/` של
  כל כלי.
- **בדיקות ותיעוד.** `tests/` (pytest ו‑`node --test`) רצים בכל דחיפה דרך
  `tests.yml`. כל תיקון ותוספת מתועדים ב‑`docs/CHANGELOG.md`.
- **התראות.** "הקו בזמן" שולח התראות דחיפה (OneSignal) על שינויים בקווים שנבחרו.

## יצירה

הפלטפורמה הגתה, כוונה ונאצרה על‑ידי **שלמה הרטמן**: הרעיון, הגדרת הכלים,
החלטות המוצר והעיצוב, ובחירת מה לשמור ומה לשנות. המימוש בפועל (קוד, עיצוב
וטקסטים) נכתב בעזרת מודל בינה מלאכותית לפי ההנחיות והכיוון שלו.

## נתונים

נתוני התחבורה הציבורית (GTFS, שידורי המיקום, לוחות הרישוי, מסמכי המכרזים ומאגרים
פתוחים נוספים) הם של **משרד התחבורה** ושל מקורות ממשלתיים אחרים (הלשכה המרכזית
לסטטיסטיקה, השירות המטאורולוגי, משרד הרישוי), אינם בבעלות בעל האתר, וכפופים
לרישיונות ולתנאי השימוש של בעליהם. נתוני מפה מ‑OpenStreetMap תחת רישיון ODbL.
ספריות צד‑שלישי הנטענות על‑ידי האתר (React, Leaflet, Babel, Tailwind) נותרות
תחת הרישיונות שלהן.
