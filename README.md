# ארכיון עבודה — משחק הקווים וסרטוני קידום (23.11.2026)

ענף ארכיון בלבד. **לא מחובר למשחק ולא לאתר**: אין כאן קוד שהאתר טוען, והענף לא ממוזג ל-main.
נשמר מסביבת העבודה של Claude לבקשת שלמה (23.11), כדי לפנות את הדיסק שם בלי לאבד את העבודה.

נשמרו הסרטונים הסופיים והקוד שיצר אותם. **לא נשמרו** תמונות הביניים (אלפי פריימים, PNG/JPG בתיקיות fr/, frames/, seq/,
before/ וכו', כ-3GB) — הן נוצרות מחדש מהקוד, ורק היו מנפחות את המאגר.

## eyeplay/ — המשחק בתצוגות החגים

סרטונים קצרים של מסך המשחק בעיצוב רגיל ובעיצובי החגים, לבדיקה בעין של איך כל עיצוב נראה.
- בשם הקובץ: החג (`regular` רגיל, `rosh` ראש השנה, `sukkot` סוכות, `hanukkah` חנוכה, `tubishvat` ט"ו בשבט, `purim` פורים,
  `pesach` פסח, `atzmaut` יום העצמאות, `lagbaomer` ל"ג בעומר, `shavuot` שבועות) והרוחב — `390` טלפון, `1280` מחשב.
- `*-all-*` — כל האנימציות של החג ברצף.
- `hanukkah-eat/light/spin`, `purim-eat/read/wear` (בשורש) — אנימציה אחת של הדמות בכל סרטון.
- `v2/` … `v5/` — סבבים מתוקנים לפי ההערות. **v5 הוא האחרון** (רק `regular`). v4 — רגיל ועוד חמישה חגים, v3 ו-v2 — כל החגים.

## promo/ — סרטוני קידום

- `bus-game-promo-vertical.mp4` — סרטון קידום אנכי (לטלפון) למשחק הקווים: "אני בונה משחק — משחק קווי אוטובוס בקריית מלאכי,
  עם הרחובות והתחנות האמיתיים".
  - `rec.js`, `lib.js`, `overlay.js` — מצלמים את המשחק בדפדפן ומוסיפים כיתובים; `assemble.sh` — מרכיב את הפריימים לסרטון (ffmpeg).
  - `bench.js`, `explore.js`, `ex2.js`, `ex3.js` — ניסויים: מהירות הצילום ובחירת רגעים מהמשחק.
  - `font/` — הגופנים של הכיתובים.
- `promo_v1.mp4`, `promo_silent.mp4` — סרטון קידום ל"מצגת לשינוי בקו" (עם קול ובלי קול).
  - `src/record.cjs`, `src/cards.html` — ההקלטה בדפדפן (Playwright) והכרטיסים שבין הקטעים; `src/video-probe.yml` — ה-workflow שהריץ אותה.
  - `drytest/` ו-`repo/tmp-video/` — ריצות ניסיון של אותו סרטון: `a-intro`, `b-site`, `c-end` (שלושת הקטעים) ו-`promo_silent` (הכול יחד).
  - `dry/` — בדיקות קטנות של ההקלטה (probe, sc, p4).
  - `promo_sheet.png`, `score-spec.png` — דף סיכום של הפריימים ומפרט הלוח שעל המסך.
