# משחק הקווים — קריית מלאכי (אב-טיפוס, לא באתר)

משחק תלת־ממדי בדפדפן: מתכננים קווי אוטובוס על מפה אמיתית של קריית מלאכי, והאוטובוסים נוסעים ברחובות,
עוצרים בתחנות, פותחים דלתות, ונוסעים עולים ויורדים.

הרצה מקומית: `python3 -m http.server` מתוך התיקייה הזו, ואז `http://localhost:8000/`.
בלי שלב בנייה: three.js נמצא ב-`vendor/three`. `?placeholders` — דגמים פשוטים במקום ה-GLB, `?fps` — מונה פריימים, `?noshadow` — בלי צללי שמש (גם נכבים לבד במכשיר איטי מאוד).

## מבנה

| קובץ | מה |
|---|---|
| `js/world.js` | קרקע, שטחים ירוקים, רחובות + אבן שפה + מדרכות, בניינים מוחלצים (קירות בגוונים, גגות אפורים), עצים |
| `js/look.js` | המראה: שמש אחת עם צל (מפת צל 1024 בטלפון, המסגרת עוקבת אחרי המצלמה), אור שמיים, מיפוי טונים ניטרלי, שמיים במעבר צבע ואובך לאופק. בלי עיבוד-אחרי |
| `js/graph.js` | רשת הנסיעה, Dijkstra, קו שבור, פרופיל מהירות |
| `js/lines.js` | קו: מסלול בין תחנות, ציור, שמירה ב-localStorage |
| `js/sim.js` | שעון, יציאות לפי תדירות (רק כשיש רכב פנוי ורק בשעות הפעילות), נסיעה, עצירות, עולים/יורדים, מעברים בין קווים, קיבולת, נשארו/ויתרו, עריכת מסלול בלי שאוטובוסים "יקפצו". קו שעובר באותה תחנה פעמיים: מי שמחכה לפעם השנייה עולה כבר לאוטובוס שהגיע, אם זה לא מאחר אותו ביותר מ-5 דק'. קו מעגלי (התחנה האחרונה היא הראשונה): האוטובוס לא נעלם במסוף אלא ממשיך כנסיעה הבאה, והממתינים שם עולים אליו (בלי ציור) |
| `js/demand.js` | ביקוש מאיפה לאן: מודל כבידה לפי שעה, מסלולים בקווים (ישיר או עם עד 2 מעברים, הליכה עד 400 מ'), סיכוי לנסוע, סיכומים לגרפים ול"חסר חיבור" |
| `js/demandview.js` | שכבת "מאיפה לאן" במפה: השכונות בגבולות האמיתיים, בגוון רך לפי השימוש העיקרי (מגורים/עבודה/לימודים/מסחר). לכל שכונה סמל (צורה) משלה — בסיכה, בכרטיס, בסמלי הביקוש ובטבלה. ליד כל שכונה: סמלים של שכונות היעד (סמל = כמה נוסעים בשעה; מלא אדום — אין קו, חצי כתום — חלקי, חלול אפור — יש קו). הקשה על שכונה — חיצים ליעדים, מספר בקצה כל חץ, וטבלה |
| `js/fleet.js` | סוגי רכבים, מחירי קנייה וליסינג, קופה (כרטיסים, סבסוד ממשלתי לכל ק"מ בשירות, ק"מ, שעות נהג, ליסינג, קנייה/מכירה), סיכום יומי, שמירה |
| `js/night.js` | הרצה מהירה (×200) כשאף קו לא פועל ואין אוטובוס בדרך — בדרך כלל בלילה |
| `js/stops.js` | התחנות: סככה כמו בתחנה אמיתית בקריית מלאכי (פלדה כהה, רפפות, זכוכית כהה, ספסל נירוסטה, לוח מידע ושלטי קווים), עמוד עם שלט התחנה, אבן שפה אדום-צהוב ומרצפות; מקומות ההמתנה. חלקים קבועים ב-InstancedMesh, שלטים עם טקסט רק לתחנות קרובות |
| `js/actors.js` | האוטובוסים והאנשים (GLB, ואם חסר — דגם פשוט). מי שיורד כדי לעבור לקו אחר הולך (בקו ישר) לתחנה של הקו הבא ומצטרף שם לממתינים |
| `js/sitting.js` | ממתינים שיושבים על הספסל בסככה: תנוחת ישיבה (IK, כמו הנהג ב-`js/driver.js`) אפויה פעם אחת לכל דגם ומצוירת בקבוצה; כשהאוטובוס מגיע הם קמים (מעבר הדרגתי לעמידה) והולכים לדלת. עד שלושה בכל סככה, מבוגרים קודם; בתחנה בלי סככה — רק עומדים |
| `js/cameras.js` | מצבי מצלמה. חופשי ומעקב פעילים; נהג/פקח/נוסע — מקום שמור לשלב הבא |
| `js/main.js` | חיבור הכל + ממשק |

## נתונים ונכסים — שלבים נפרדים, לא בזמן המשחק

1. **OSM**: ‏`.github/workflows/bus-game-osm.yml` מוריד מ-Overpass את `world/osm_raw.json.gz` (Overpass חסום מסביבת העבודה).
2. **העיר**: `python3 tools/build_city.py` ← `world/city.json` (בניינים, רחובות, רשת נסיעה, תחנות GTFS מ-`world/gtfs_stops.csv`).
   **הביקוש**: `python3 tools/build_demand.py` ← `world/demand.json` (צריך shapely). האזורים: 16 השכונות של קריית מלאכי
   (`world/neighbourhoods.json` — שכבה 22 של GovMap / מפ"י, דרך "גרסאות לעם", ספטמבר 2026; אותם נתונים כמו ב"קו בזמן")
   ו-5 מושבים מסביב (שטח המגורים ב-OSM) — רק מה שיש בו תחנה. תחנה ← השכונה שהיא בתוכה; מחוץ לכולן — עד 150 מ' לשכונה,
   עד 400 מ' למושב, אחרת כמו התחנה הקרובה. לכל תחנה: תושבים ומשקל עבודה/לימודים/קניות לפי סוגי הבניינים והשימושים ב-OSM,
   ולכל שכונה סמל (צורה) — שכנות לא מקבלות צורות דומות. רץ מקומית, בלי הורדה.

## הביקוש — במספרים

- כ-23,000 תושבים בתחום המפה. כל תושב: 0.24 נסיעות לעבודה, 0.12 ללימודים ו-0.32 לקניות ושונות ביום (הלוך; החזור הפוך),
  רק נסיעות של יותר מ-400 מ'. יוצא בערך 21,000 "רוצים לנסוע" ביום, וכ-3,000 בשעה בשיא הבוקר (7–8).
- מי שיש לו מסלול נוסע בסיכוי של עד 90%, לפי זמן מורגש (הליכה ×1.5, המתנה ×1.5, נסיעה, 5 דק' לכל מעבר) לעומת 18 דק' + 9 דק' לק"מ.
  רשת של 5 קווים סבירים מסיעה בערך 4,000–5,000 ביום.
- מעבר בחינם (כמו רב-קו): כרטיס אחד לנסיעה. קווים מקבילים: מחכים לכל קו שמגיע ישר ליעד.

## הכסף — במספרים

- מתחילים עם ₪60,000. כרטיס ₪6, וסבסוד ממשלתי ₪10 לכל ק"מ בשירות (לא על החזרה הריקה למסוף).
- רכב רגיל: ₪6,000 לקנייה או ₪600 ליום בליסינג (מיניבוס 3,000/300, מפרקי 10,000/1,000, חשמלי 7,500/750).
- רשת של 5 קווים סבירים (12 אוטובוסים רגילים) מרוויחה כ-₪15,000 ביום; אוטובוס בקו טוב מחזיר את מחירו ב-2.5–4 ימים.
  קו כמעט ריק, או קו עם יותר מדי אוטובוסים, מפסיד.
- שמירה מלפני השינוי (v1, מחירים פי 33): הקופה מחולקת ב-33 בטעינה.
3. **דגמים**: ‏`.github/workflows/bus-game-assets.yml` מריץ Blender: בונה את האוטובוס ואת האדם בקוד של הענף
   `claude/blender-test`, ומייצא עם `tools/export_bus.py` ו-`tools/export_person.py` ל-`assets/bus.glb` ול-`assets/people/person_<n>.glb`.
   האנשים: כמה אנשים שונים (גברים ונשים, גילים, עור, שיער ובגדים — נכסי MakeHuman CC0 בלבד), מוגדרים ב-`tools/person_variants.py`.
   כל אחד עם הליכה (CMU 16_15) ועמידה, והטקסטורות המקוריות. רשימת הקבצים: `assets/people/people.json`.
   הרצה ידנית של חלק מהאנשים: workflow_dispatch עם `only` (למשל `0,3`), והאוטובוס עם `bus`.
4. **בלי glb**: במקומות שלא מגישים קבצי ‎.glb‏ (התצוגה המקדימה הפרטית) — `python3 tools/glb_to_gltf_json.py assets/bus.glb assets/people/*.glb`
   יוצר ליד כל קובץ `X.gltf.json`, והמשחק טוען אותו אם ה-glb חסר. לא שומרים אותם בריפו (`.gitignore`).
   אפשר גם מקומית עם `pip install bpy` (חוץ מהאדם, שצריך את התוסף MPFB).
