# כמה עמוס הקרון

אפליקציית אנדרואיד פרטית של שלמה (12.10.2026). לא חלק מהאתר ולא מקושרת ממנו.

סורקת 15 שניות את שידורי ה-Bluetooth בסביבה, מזהה לפי מה שכל מכשיר משדר אם הוא טלפון,
אוזניות או שעון (נתוני היצרן של אפל, שדה Appearance, ומזהי שירות של גוגל), וסופרת רק את מה
שנראה בתוך הקרון — לפי אורך הקרון ואיפה עומדים (מרחק משוער מעוצמת האות). התוצאה: ריק /
בינוני / מלא, ומספר אנשים משוער אחרי כיול (סופרים פעם אחת בעיניים).

לא נשמרות כתובות של מכשירים — רק הספירה, ויחס הכיול בהגדרות של האפליקציה.

הבנייה: `.github/workflows/kav-karon-apk.yml` — APK לבדיקה בעמוד הריצה (artifact `kav-karon-apk`).
מתקינים בטלפון עם "התקנה ממקורות לא ידועים".
